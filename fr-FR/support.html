Assistance

Écrivez à info@ifgecommerce.com pour obtenir de l’aide avec Solitaire Unbound.

Indiquez le modèle, la version d’iOS et celle de l’app. Décrivez le problème et les étapes pour le reproduire. Masquez les données personnelles des captures.

N’envoyez jamais de mot de passe, code d’accès, numéro de carte ou identifiants Apple.

Utilisez Restaurer les achats avec le compte Apple de l’achat. Une connexion peut être nécessaire. Restaurer Pro ne récupère pas la progression locale.

Pour les paiements et remboursements, contactez l’assistance Apple.
